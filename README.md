# SheFind — Women's Safe Toilet Finder

> "Find clean. Stay safe. Go confidently."

## About
SheFind is a mobile-first web app that helps women in Madurai, Tamil Nadu find clean and safe public toilets near temples, bus stands, hospitals, markets and parks.

Built for the AWS User Group Madurai — March Skill Sprint: Build for Her 💜

## Features
- Interactive Leaflet.js map centered on Madurai
- 25 real Madurai toilet locations with color-coded pins
- Cleanliness and safety ratings with star system
- Facilities info — water, lock, lights, pad machine, attendant
- Safety badges — Women Verified Safe / Needs Caution / Avoid
- Smart search by landmark or area name
- Tamil and English language toggle
- Community toilet reporting
- AI-powered safety tips based on time and ratings

## Tech Stack
- HTML, CSS, JavaScript (single file)
- Leaflet.js for interactive map
- localStorage for saving ratings
- No frameworks, no backend needed
