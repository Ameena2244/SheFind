# SheFind Project

## Overview
SheFind is a women's safe toilet finder app for Madurai, Tamil Nadu. The app helps women locate clean, safe public toilets with detailed ratings and facility information.

## Key Features
- Interactive map with 25 real Madurai toilet locations
- Color-coded safety ratings (Green/Yellow/Red pins)
- Detailed facility information and user reviews
- Tamil/English language support
- Community features for adding new locations
- Mobile-first responsive design

## Tech Stack
- Single HTML file with inline CSS/JavaScript
- Leaflet.js for interactive mapping
- localStorage for data persistence
- No backend or external APIs required

## Design Principles
- Mobile-first, accessible design
- Purple theme (#7C3AED) for trust and safety
- Clean, minimal UI suitable for all ages
- Built with women's safety and comfort in mind
